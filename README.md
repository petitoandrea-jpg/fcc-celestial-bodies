# fcc-celestial-bodies
Progettazione e popolamento da zero di un modello di dati relazionale per mappare corpi celesti (galassie, stelle, pianeti, lune).

Caratteristiche principali:

Creazione di uno schema strutturato con 5 tabelle correlate tramite relazioni uno-a-molti e gerarchie ad albero.

Utilizzo rigoroso dei tipi di dati PostgreSQL (SERIAL, INT, NUMERIC, VARCHAR, TEXT, BOOLEAN).

Implementazione di vincoli di integrità: chiavi primarie, chiavi esterne per mantenere il vincolo gerarchico, vincoli di unicità e colonne non nulle.
